# Credits

KeepFall is an original game. Its name, creatures, floors and look were made for this project.

## Art and sound

All art is drawn in code with canvas shapes. All sound effects are made in code with the Web Audio API. No outside image, font or sound files are used. Text uses the serif font already on the player's device.

## Tools

- TypeScript (Apache 2.0 license)
- Vite (MIT license)

These are build tools only. Nothing from them ships as game content.

## Outside assets

None. If an outside asset is ever added, list it here with its author, source and license.
