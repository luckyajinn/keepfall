# Credits

KeepFall is an original game. Its name, creatures, floors and look were made for this project.

## Art and sound

All art is pixel art drawn in code: the characters, tiles, backdrops, icons, touch buttons and the pixel font were all made for this project. The art rules are written at the top of `src/render/pixel.ts`. All sound effects are made in code with the Web Audio API. No outside image, font or sound files are used. Text uses the serif font already on the player's device.

## Tools

- TypeScript (Apache 2.0 license)
- Vite (MIT license)

These are build tools only. Nothing from them ships as game content.
